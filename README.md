# pi-ai-manager

Pi Coding Agent 的交互式网关与模型管理扩展。通过 `/ai-manager` 添加、编辑网关，发现模型，检查连通性，管理在 Pi 中启用的模型。

当前适配 Pi **0.85.1–0.85.x**，需要 Node.js **22.19.0 或更新版本**。

## 安装和加载

```bash
pi install git:github.com/mystudy-hub/pi-ai-manager
```

本地开发或修改已有安装：

```bash
npm install
npm run check
```

源码需要可解析的 Pi SDK；测试也需要已安装的 Pi。若没有本地或全局 Pi，可在开发目录安装：

```bash
npm install --no-save --package-lock=false @earendil-works/pi-coding-agent@0.85.1
```

也可以用 `PI_CODING_AGENT_PACKAGE_DIR` 指定已安装 Pi 的包目录供测试加载。修改源码后，在 Pi 中执行 `/reload`，再打开 `/ai-manager`；也可以重启 Pi。

## 保存方式

**所有更改先保留为草稿。** 网关增删改、模型启用、协议和上下文设置、刷新取得的元数据、测试结果，都在主界面按 **Enter / Ctrl+S** 后保存并生效。按 **Esc** 退出主界面会丢弃草稿。

新网关发现的模型默认全部未启用。选择需要的模型后保存。表单中的 Enter 只将表单内容加入草稿；表单、详情、帮助、菜单、确认框中的 Esc 返回上一层。

测试或发现模型期间可以继续浏览、搜索、筛选和查看详情，配置编辑暂时禁用。主界面的 **Esc 只停止当前任务**，保留草稿和已完成的模型测试；之后可保存，或再按 Esc 放弃并退出。**Ctrl+C** 可从任意页面停止任务。运行中在主界面按 Enter / Ctrl+S 会停止任务、保存已完成结果并退出。停止不能撤回网关已经收到的请求。

保存时锁定网关配置和 Pi 的设置文件，合并不同会话的独立修改。相同字段的冲突会明确报错并保持管理器打开；连接地址与凭据作为同一组处理，避免合并成错误的组合。遇到冲突时退出并重新打开管理器，再应用需要的修改。

## 浏览与草稿提示

管理器按终端可用高度显示，保留底部操作提示。宽度达到 90 列时显示网关、模型两栏；较窄时只显示当前栏，用 Tab / ←→ 切换。排序和刷新会保持选中的模型，各网关分别记住选中项和滚动位置。

默认显示全部模型，已启用模型排在前面。`f` 打开状态和质量筛选，也可重置所有筛选及搜索；界面显示匹配数 / 模型总数。`/` 实时搜索，Enter 保留搜索，Esc 恢复进入搜索前的条件。

列表显示启用状态、模型名称、健康状态和延迟；模型栏足够宽时也显示接入协议、推理声明和上下文长度。选中模型的摘要显示这三项的当前值和快捷键，窄屏会分行显示；上下文前的“约”表示估算。按 `p` 切换当前模型的接入协议，按 `g` / `b` 切换推理声明，按 **Shift+C（大写 C）** 设置上下文长度。

`i` 查看完整模型 ID、协议、输入能力、上下文和输出上限、价格及最近测试原因。模型详情页也支持 `p`、`g` / `b` 和 `C`；上下文表单应用或取消后返回详情，修改仍需回到主界面保存。在网关栏按 `i` 查看连接和凭据来源。详情可滚动，Esc / i 返回。凭据“已配置”不代表连通性验证成功。

标题显示“未保存：N 项”，`v` 查看变更，分别列出配置、测试和发现记录。计数来自草稿与打开时配置的实际差异，改回原值或撤销后相应项目会消失，密钥值不会出现在清单中。测试失败原因只在当前会话详情中保留；保存的健康与延迟记录仍可跨会话查看。

按 `:` 打开操作菜单，输入操作名称或快捷键搜索，用 ↑↓ 选择、Enter 执行。菜单和帮助使用同一份操作定义，不必记住所有大小写快捷键。

## 凭据与网络

- 表单 API Key 默认为字面量，`!`、`$` 不会被当成命令或环境变量表达式。输入 `env:MY_GATEWAY_KEY` 明确引用环境变量；留空沿用 Pi 的凭据解析。
- Pi 的运行时凭据和 `/login` 凭据优先于这里配置的密钥。模型发现遵循相同优先级。需要替换此类凭据时，通过 Pi 的登录流程管理。
- 远程网关默认要求 HTTPS；真实回环地址支持 HTTP。可信内网确实需要明文 HTTP 时，可在对应网关配置中显式设置 `allowInsecureHttp: true`。旧 HTTP 条目会保留供编辑，但没有此设置时不会注册或请求。
- Base URL 不接受内嵌用户名、密码、查询参数和片段；可以包含部署路径或结尾 `/v1`。发现请求使用 `/v1/models`，拒绝自动跳转。
- 发现响应上限 5 MiB、10,000 个模型，超时覆盖连接和响应体。模型 ID 会过滤终端控制字符、保留属性名和重复项。取消会中止请求、重试等待和限速等待，迟到结果不再更新草稿或配置。
- 扩展不会修改 Node.js 进程的全局 TLS 参数。

支持的协议是 `openai-completions`、`openai-responses`、`anthropic-messages`。Gemini 等模型可以通过网关的兼容协议使用，当前不实现原生 Gemini 协议。协议发现依据网关返回的 endpoint 类型；缺失或含糊时，需根据网关文档选择默认协议。

## 指标与模型能力

连通性测试每个模型最多发送 3 个简短问题，每个请求最多输出 256 token，单次超时 30 秒，不自动重试。默认并发为 3、同一网关请求间隔 500 毫秒；可配置并发 1–10、间隔 0–10,000 毫秒。测试会产生网关费用，界面的输出上限不包含输入 token 或网关额外计费。

健康记录超过 24 小时按未知展示和排序。延迟指标只统计成功请求。名称推荐是启发式规则，连通性测试只检查是否收到有效响应；两者都不能验证模型真实身份或回答质量。去重保留 `thinking`、`fast` 等变体后缀，并不把这些模型当作同一模型。

上下文、输出限制按已有配置、发现元数据、Pi 模型目录的顺序确定。目录没有精确匹配时，回退为上下文 **32,768**、最大输出 **8,192**，输出限制不超过上下文。界面会标记估算的上下文，仍应按网关文档核实。

价格不会沿用原厂价格来推断网关费用。未填写 `cost` 时显示未知；由于 Pi 注册接口需要数值，会传入 0 作为占位，因此 **Pi 显示 0 成本不代表免费**。可在模型配置中填写每百万 token 的价格：

```json
{
  "cost": { "input": 1, "output": 3, "cacheRead": 0.1, "cacheWrite": 0 }
}
```

`modelApiOverrides` 保留简单正则规则，例如 `^gpt-` 和精确模型规则。为避免阻塞界面，忽略分组、回溯引用、花括号重复及包含多个量词的复杂模式。`p` 只为选中模型写入精确规则，回到 auto 会去掉此规则，继续遵循其余网关规则和发现结果。摘要中的“规则”表示有匹配的覆盖规则；列表和详情显示与 Pi 注册一致的有效协议。撤销协议修改会恢复原来的规则顺序。界面的 `e` / `x` 使用 glob，不接受正则表达式。

## 配置、备份和恢复

所有路径都以 Pi 的 agent 目录为准，默认是 `~/.pi/agent`；通过 `PI_CODING_AGENT_DIR` 切换目录时，配置和备份一起切换。

```text
extension-settings/provider-ai.json          网关、模型、测试设置
extension-settings/backups/                  最近 10 份配置备份
extension-settings/provider-ai.pending.json  中断保存的同步日志，仅含网关名称
settings.json                               Pi 的 enabledModels 范围
```

主配置、备份和同步日志通过原子替换写入，POSIX 下权限为 `0600`。字面量密钥仍以明文存于主配置和历史备份，优先使用环境变量引用可减少密钥副本；之后切换为环境变量不会自动清除旧备份。

配置损坏时，读取路径会依次校验备份，找到有效备份才恢复。没有有效备份时报告错误并保留原文件。若配置已写入但 `settings.json` 同步失败，会明确报告部分完成，下次读取或保存时重放日志。不会将同步失败报告为保存成功，也不会覆盖其他网关或用户自定义的设置项。
