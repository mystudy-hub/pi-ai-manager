## ✨ 新增功能

### 1. 自动备份和恢复 🔒

**现在：配置永不丢失！**

- ✅ 每次保存前自动备份

### 2. 撤销功能 ↩️

**误操作？一键撤销！**

#### 支持的操作
- 自动选择模型 (`a`)
- 去重操作 (`d`)
- 批量启用/禁用 (`e`/`x`)
- 单个模型切换 (`Space`)

#### 使用方法
1. 执行任何批量操作
2. 看到不满意？按 `u` 键撤销
3. 可以撤销最近 50 个操作

#### 示例
```
1. 按 'a' 自动选择了 50 个模型
2. 发现选多了
3. 按 'u' 撤销
4. ✅ 恢复到之前的状态
```

**提示：** 有可撤销操作时，帮助栏会显示 "u: undo"

## 📋 完整键盘快捷键

### 导航
- `↑↓` - 选择模型
- `←→` - 切换网关
- `/` - 过滤模型
- `s` - 切换排序方式
- `q` - 质量过滤

### 操作
- `Space` - 切换模型启用/禁用
- `t` - 测试选中的模型
- `T` - 测试所有启用的模型
- `p` - 切换 API 类型
- `a` - 自动选择推荐模型
- `d` - 去重（禁用较慢的重复模型）
- `e` - 按模式启用模型
- `x` - 按模式禁用模型
- **`u` - 撤销上一个操作** ⭐ 新功能

### 网关管理
- `n` - 添加新网关
- `D` 或 `dd` - 删除当前网关
- `r` - 刷新当前网关
- `R` - 刷新所有网关
- `A` - 自动发现网关

### 其他
- `?` - 显示/隐藏帮助
- `Enter` - 保存并退出
- `Esc` - 取消（不保存）

## 🔧 故障排除

### 问题：看不到撤销提示

**原因：** 还没有可撤销的操作

**解决：** 执行任何批量操作（`a`, `d`, `e`, `x`），然后查看状态栏

---

### 问题：找不到备份文件

**位置：**
```bash
~/.pi/agent/extensions/ai-gateway/.backups/
```

**检查：**
```bash
ls -la ~/.pi/agent/extensions/ai-gateway/.backups/
```

如果目录不存在，会在第一次保存时自动创建。

---

### 问题：性能没有提升

**可能原因：**
1. 模型数量较少（< 100）：优化效果不明显
2. 首次加载：需要建立缓存
3. 网络慢：缓存未生效

**验证：**
- 多次切换网关，观察第二次是否更快
- 检查是否有网络请求缓存命中

## 🎓 进阶技巧

### 批量操作模式
使用 `e` (enable) 和 `x` (exclude) 按模式操作：

```
1. 按 'e' 进入启用模式
2. 输入模式：gpt-4*
3. 回车确认
4. ✅ 所有 gpt-4 开头的模型被启用
```

支持的模式：
- `gpt-4*` - 所有 gpt-4 开头的模型
- `*-turbo` - 所有以 -turbo 结尾的模型
- `claude-*-20*` - 所有符合的 Claude 模型

### 快速去重工作流
```
1. 按 'R' 刷新所有网关（获取最新模型列表）
2. 按 'd' 去重（自动禁用较慢的重复模型）
3. 按 'Enter' 保存
4. ✅ 完成！每个模型只保留最快的实例
```
