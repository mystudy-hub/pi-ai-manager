## ⌨️ 新快捷键

- **`u`** - 撤销上一个操作 ⭐ 新功能

其他快捷键：
- `a` - 自动选择推荐模型
- `d` - 去重（禁用较慢的重复模型）
- `e` - 按模式启用模型
- `x` - 按模式禁用模型
- `/` - 过滤模型
- `?` - 显示帮助

完整列表见 [QUICK-START-v3.1.md](QUICK-START-v3.1.md)

## 🔧 故障排除

### 问题：看不到 `/ai-manager` 命令

**解决：**
```bash
# 重启 pi
exit
pi
```

### 问题：撤销功能不工作

**检查：**
1. 确保执行了批量操作（`a`, `d`, `e`, `x`）
2. 查看状态栏是否显示 "u: undo"
3. 如果没有显示，说明没有可撤销的操作

### 问题：找不到备份文件

**位置：**
```bash
~/.pi/agent/extensions/ai-gateway/.backups/
```

**检查：**
```bash
ls -la ~/.pi/agent/extensions/ai-gateway/.backups/
```

如果目录不存在，会在第一次保存时自动创建。
